# NovaTekno Mağaza (Expo SDK 58 + Expo Router)

Expo SDK 58 uyumlu, Koyu Gece (Dark Slate) & Zümrüt Yeşili temalı mobil e-ticaret uygulaması.

## Visual Studio Code ile Kurulum ve Çalıştırma

1. ZIP dosyasını klasöre çıkarın ve **Visual Studio Code** ile `eticaret-lab` klasörünü açın (`File -> Open Folder`).
2. VS Code terminalini açın (`Terminal -> New Terminal`) ve paketleri yükleyip SDK 58 ile tam hizalayın:
   ```bash
   npm install
   npx expo install --fix
   ```
3. Uygulamayı Expo Go ile başlatın:
   ```bash
   npx expo start --go --clear
   ```
4. Telefonunuzdaki **Expo Go** uygulaması ile terminaldeki QR kodu okutun (veya tarayıcıda açmak için `w` tuşuna basın).
